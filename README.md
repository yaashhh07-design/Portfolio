- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

    ├── profile.png

## Run locally

Simply open `index.html` in a browser.

For the best development experience, use VS Code + Live Server.

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Make sure `index.html` is in the repository root.
4. Go to Settings → Pages.
5. Select the main branch and root folder.
6. Save and open the generated GitHub Pages URL.

## Customize

Main personal details are in `index.html`.
Colors, layout, cards and animations are in `style.css`.
Interactive behavior and animations are in `script.js`.

The contact form uses a `mailto:` action, so it does not require a backend.
